# Iniciar

Retomar este projeto de vida; nunca recriar do zero.

1. Ler `_ia/LEIA-IA.md` e os arquivos de retomada indicados.
2. Resumir fase, última ação, pendências e próxima ação em poucas linhas.
3. Atender o pedido explícito de Alex, se houver.
4. Se ele apenas disser iniciar, retomar a próxima ação registrada; quando ela depender de uma escolha pessoal, fazer uma pergunta objetiva.

Não exigir confirmação de uma ação já solicitada. Preservar perfil, decisões e histórico; registrar correções informadas por Alex com a data.
